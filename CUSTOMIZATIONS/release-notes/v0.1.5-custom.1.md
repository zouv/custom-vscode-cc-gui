## 本次自定义内容

本 fork 的**首个发布**。相对上游 `8ba39913` 的全部改动如下。

### 1. 改名 `CC GUI (Custom)`，命名空间全量改为 `ccgc.*`（CUSTOM-20261009-003）

- 显示名 `CCGUI / CC GUI（custom fork · …）` → **`CC GUI (Custom)`**；扩展 ID `zouv.custom-vscode-cc-gui`
- 命令 id / 配置键 / 上下文键 / 视图 id / 菜单 group 一律 `ccGui.*` → `ccgc.*`；
  视图容器 `cc-gui-activity` / `cc-gui-secondary` → `ccgc-activity` / `ccgc-secondary`；
  输出通道名 → `CC GUI (Custom)`
- **收益**：本 fork 可与上游 vscode-cc-gui **同时安装**，不会再出现重复的命令/视图贡献与配置互相抢占
- ⚠️ **升级提示**：若你装过本 fork 更早的未发布版本，设置里的 `ccGui.nodePath` / `ccGui.enableDebugLog`
  需改名为 `ccgc.nodePath` / `ccgc.enableDebugLog`（命令面板与侧边栏的入口名也换成了 `CC GUI (Custom)`）

### 2. 新增 `npm run dev:host`（CUSTOM-20261009-002）

一条命令完成「构建 → 启动 Extension Development Host」，用于手工点击验收（等价于 F5，但不附加调试器）：

```bash
npm run dev:host                              # 工作区 = 本仓库
npm run dev:host -- "D:\path\to\your\project"  # 用别的目录当工作区
npm run dev:host -- --no-build                 # 跳过构建
```

宿主环境与 `.vscode/launch.json` 对齐（`.vscode-dev/` 隔离 profile，只加载本扩展）。

### 3. 仓库基建（CUSTOM-20260923-001）

- fork 标识：`name` / `publisher` / `version` / `.gitignore` / `.vscodeignore` / `.gitattributes`
- 自定义开发机制：`CUSTOMIZATIONS/`（规则、改动账本、代码地图、坑点库）+ 脚本套件
  （`manager.sh` 三包统一入口、`package-vsix.sh` 打包 + 内容断言、`check-registry.sh` 登记一致性、`publish-release.mjs` 发布）
- 4 个项目级 skill：`ccgui-record-change` / `ccgui-merge-upstream` / `ccgui-release` / `ccgui-publish`

## 安装

1. 下载下方 `custom-vscode-cc-gui-0.1.5-custom.1.vsix`
2. VS Code → 扩展 → 右上角 `...` → **Install from VSIX…**
3. 本机需有 Node ≥ 20 与对应 CLI（Claude Code / Codex / OpenCode / Kimi 等）
